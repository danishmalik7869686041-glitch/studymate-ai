\# StudyMate AI



StudyMate AI is an AI-powered student study assistant designed to help students with study questions, study planning, quizzes, and PDF-based learning.



The project also includes a Model Context Protocol (MCP) server that exposes StudyMate AI through a Streamable HTTP MCP endpoint.



\## Features



\- AI-powered study question answering

\- Study plan generation

\- Quiz functionality

\- PDF upload and question answering

\- Dark mode student-friendly interface

\- MCP integration through Streamable HTTP

\- `ask\_studymate` MCP tool

\- Local and self-hosted MCP server support
